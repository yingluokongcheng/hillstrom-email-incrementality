# History and preservation

1. **Audit v1:** fixed plan, source metadata, missingness/allocation/balance checks, identical-row diagnostics and prospective scenario power. All 38 files are preserved in `history/audit/`; three raw/row-level files are restored locally rather than included in the public bundle. Hashes are recorded in [audit_preservation.json](audit_preservation.json).
2. **Effects v1:** overall primary effects, all regional and secondary results, tests, offline reproduction and report screenshots. The original project remains untouched on the author's machine. Its 70-file hashes are recorded in [effects_preservation.json](effects_preservation.json).
3. **GitHub review package:** English/Chinese documentation and standalone download/verification entry points. No statistical settings, results, tests or frozen scientific code changed. Replaced original READMEs, manifest and local verifier are retained in `history/effects-v1/`. Other original effect files retain their original content at the package root. The old root manifest describes the original version; the new root manifest describes this package.

Historical verification JSON contains the original machine's local paths and timestamps. Those are provenance records, not required checkout locations. The README snapshots under `history/effects-v1/` retain links relative to their original project root; use the current root README for navigation. Historical README statements such as “no publication” refer to that stage; the review package was subsequently approved for publication as [hillstrom-email-incrementality](https://github.com/yingluokongcheng/hillstrom-email-incrementality). The original local review package is retained unchanged. New verification results are stored separately, never used to replace earlier success/failure history. `.gitattributes` disables Git newline conversion to preserve frozen hashes on checkout.

An original data audit is not independent verification of the source experiment. Likewise, byte-identical reproduction verifies computational consistency, not the truth of causal assumptions or transportability to another business.

# Hillstrom 固定分析计划 v1

确认日期：2026-10-17（America/New_York）。本文件在本次下载与数据计算前建立。

## 已确认的研究口径

- 公开随机实验的回顾性分析；不是新开展的实验或真正的事前预注册。
- 客户为分析单位，按原始分配组；不以访问/购买筛选分析样本。
- 唯一主指标：两周 conversion；主要效果为购买率绝对差（百分点）。
- 主比较：Mens E-Mail - No E-Mail；Womens E-Mail - No E-Mail。
- 双侧独立比例差 score 检验及 score 区间，Miettinen–Nurminen 方差修正。
- 两项比较 Bonferroni 家族 alpha=0.05，每项 alpha=0.025，97.5% 区间。
- 任何主比较购买/未购买格计数 <10 或区间求解失败，暂停常规显著性结论，不临时选择更显著的方法。
- 访问率、人均消费额为探索；消费额包括零，保留大额值。消费额区间用组内 bootstrap；不输出探索显著赢家。
- 地区只有 Urban/Suburban/Rural，六项邮件-对照比较仅探索；不证明文化机制，不做地区交互检验或继续交叉切分。
- 第一版不正式比较两种邮件的优劣，不增加回归调整或模型选择。
- +0.10 个百分点（概率差 0.001，每万人10名购买客户）是情景基准，不是已验证盈利门槛。
- 样本规划固定对照概率 0.005/0.01/0.02，增量 0.001/0.002/0.003，功效 80%/90%，每项双侧 alpha=0.025；不计算观察效果的事后功效。
- 不显著不等于无效；区间跨零且包含有意义提升时说明证据不足；上限低于门槛仅排除该大小的提升，不能证明严格零效果。
- 保留不改善/负面/不确定结果，不按结果改口径或追加实验。

## 本轮执行边界：只审计

本轮允许来源/结构/分组/缺失/异常/分组前平衡审计和情景样本规划，不计算购买率差、邮件效果检验、效果区间、效果排序或地区效果。

分组与地区×分组的购买/未购买计数仅用于稀疏检查，会暴露部分结果信息；报告公开此事实，不将后续分析称为盲态分析。

SRM 用三组 1:1:1 设计的卡方拟合优度检验，p<0.001 为暂停规则；设计近似比例和随机化实现未知。背景协变量缺失不删主样本；分组/主结果缺失或非法则暂停。没有客户 ID 时，相同行不自动去重。逻辑异常保留并列清单。未解决的结构/关键结果问题先请用户确认。

样本规划使用固定概率情景与实际分配人数，采用合并零假设方差、备择非合并方差的正态近似双侧 score 功效；无观察效果输入。MDE 和需要人数为近似规划结果，不替代正式检验。地区沿用 alpha=0.025 作统一精度参照，不表示其获得确认性检验资格。

审计完成后停下，用户确认后才运行效果分析。

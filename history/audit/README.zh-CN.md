# Hillstrom 邮件实验：本地数据审计

当前只完成审计，等待本人确认；未运行效果分析，未发布GitHub。

请先打开 [中文审计报告](reports/Hillstrom数据审计.html)。包括分组比例、各字段缺失/异常、相同行、地区覆盖、三种基线下的功效/MDE、完整CSV明细及研究限制。

## 主要结论

- 原始64,000行、12字段。三组分别为21,307（男装）、21,387（女装）、21,306（不发邮件）。整体SRM p=0.903693；分组前最大绝对SMD为0.0169。
- 缺失值和预设取值/逻辑异常检查命中均为0；有7,634行涉及完全相同的组合，包含1,072种重复组合，若机械保留首行会删掉6,562行。本项目没有删除任何行。
- 相同行中7,570行的历史消费额为29.99。数据没有客户ID，无法确认相同行是重复客户还是不同客户的相同记录，不把“相同行”直接等同“重复客户”。所有样本规划依赖独立客户假设。
- 假设对照购买率1%、每项双侧alpha=0.025，识别+0.10个百分点的总体近似功效约11%，80%功效MDE约+0.32个百分点；地区更弱。基线0.5%/1%/2%、提升0.10/0.20/0.30个百分点和80%/90%功效的全部预设情景均保留。
- 可以继续固定的总体分析，但不能期待稳定检出或排除很小的提升。地区保持探索，不用“显著/不显著”的差别证明地区异质性。

## 本机启动

虚拟环境和数据已备好，双击 `Run_audit.cmd` 可重新生成报告，过程无需Google Cloud或联网。只阅读报告可直接打开 `reports/Hillstrom数据审计.html`，不需要启动服务。

也可在此项目目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/run_offline.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

新机器需先安装Python 3.12，执行英文README中的建环境、依赖安装、下载命令。首次安装与下载需普通网络；之后使用本地缓存。程序禁用Python连接/DNS调用的验证不是系统级断网测试。

## 边界与证据

固定方案与+0.10个百分点基准已确认，计划在本轮下载前保存并在来源清单记录哈希。基准是情景值，不能称为真实商业门槛。

作者下载链接证书校验失败，使用scikit-uplift文档副本，压缩MD5核对一致；尚未与作者原始文件字节对账。原始数据保留，派生地区名称将Surburban映射为Suburban。来源记录见 `data/raw/source_manifest.json`。

本轮公开分组/地区购买计数用于稀疏检查，因此并非盲态；没有计算购买率差、邮件效果p值或效果区间。`reports/verification.json` 提供测试和独立目录离线重跑证据。审计确认后才能继续效果分析。

# Hillstrom 邮件增量效果分析

[English](README.md) · [研究设计与完整结果](docs/STUDY.md) · [项目结构](docs/STRUCTURE.md) · [本地复现](docs/REPRODUCIBILITY.md)

研究问题：与不发邮件相比，两类商品营销邮件能否提高两周内的购买率？结果与预先约定的 **+0.10 个百分点**情景基准是什么关系？总体比较为主，Urban / Suburban / Rural 地区分组仅作探索。

这是公开历史实验数据的分析作品，不代表本人实施了真实业务实验，也不把观察结果写成实际落地业绩。项目补充实验设计、数据审计、统计推断、多重比较和可复现分析能力。

## 主要结果

| 邮件组相对不发邮件 | 购买率差（百分点） | 校正后区间（各 97.5%） | Bonferroni 校正 p 值 |
|---|---:|---:|---:|
| 男装商品邮件 | +0.6805 | [+0.4771, +0.8922] | 3.0484e-13 |
| 女装商品邮件 | +0.3111 | [+0.1277, +0.4992] | 0.0003143 |

两个区间下界均高于 +0.10 个百分点，但女装邮件下界距离基准较近。该基准仅为情景，不等于利润门槛；没有直接检验两种邮件谁更优。邮件名称指商品类别，不代表客户性别。

全部六个地区结果都保留。农村女装邮件的名义 95% 区间为 **[−0.1599, +0.8464] 个百分点**，跨过零：不能断言无效，也不能据此断言地区间效果不同。访问率和含零消费额的分析均为探索结果。

## 审计与结论边界

64,000 行全部保留，7,634 行涉及 1,072 种完全相同的整行模式。没有客户 ID，无法判断它们是否为同一人的重复记录，因此不机械去重，也不声称独立性已经证实。无字段缺失或预设逻辑异常；分组比例检验 p=0.9037，最大基线绝对 SMD 约 0.0169。这些诊断不能证明原始随机化和随访完整性。

原审计显示对 +0.10 个百分点的小效果检验力较低；本次观察到更大的效果并不与此矛盾。不追加基于观测效果的事后功效解释。

主分析采用校正 MN score 方法；两个正式比较控制整体第一类错误率 5%。地区使用未做多重校正的名义 95% 区间，不做地区优选。消费额保留零值，以固定种子进行 20,000 次组内 bootstrap。没有新增调参或实验。

审计阶段已经看到结局计数，不能称为盲法或纯粹预注册研究。缺少分配/投递日志、成本、毛利、退订和长期指标，不能推出利润或长期价值。
